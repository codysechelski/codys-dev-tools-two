### Description (4000)

Cody's Dev Tools puts the small utilities you reach for every day in one fast, native-feeling app. Paste something in, get the answer, and move on. No browser tabs full of ad-covered websites, and nothing you paste ever leaves your Mac.

FORMATTERS
• JSON: format, minify, validate, and sort keys
• SQL and Salesforce SOQL: expanded, compact, or minified, with keyword case options
• JavaScript, HTML, CSS, XML, Python, and Lua

CONVERTERS
• JSON ⇄ YAML and JSON ⇄ XML
• Number bases: binary, octal, decimal, hexadecimal, and any base from 2 to 36

ENCODERS AND DECODERS
• HTML entities, URLs, and Base64
• Images to Base64, with ready-to-paste CSS and HTML snippets

TEXT
• Regex Tester: build a pattern with token helpers and see every match highlighted and listed
• Diff Tool: compare two texts with changes highlighted side by side
• Line Sorter/Deduplicator, Text Analyzer, String Template Formatter, and Lorem Ipsum Generator

DATES AND TIMES
• Timestamp Converter for Unix epochs, ISO 8601, and other common formats
• Time Zone Converter with daylight-saving-aware day bars and business-hour indicators
• Cron Builder/Parser that explains a schedule and lists its next run times

AND MORE
• QR Code Generator for text, URLs, Wi-Fi, contacts, email, SMS, phone, and calendar events, saved as PNG or SVG
• UUID Generator, Markdown Table Generator, SVG Viewer, and Unicode Character Map

BUILT FOR DEVELOPERS
• Syntax-highlighted editors with line numbers and Tab indentation
• Load and save files right from the editors
• Light, dark, and system themes
• Search every tool from the sidebar and star your favorites
• Works completely offline

PRIVATE BY DESIGN
Cody's Dev Tools collects nothing. There's no account, no analytics, and no network access: everything you type or paste stays on your Mac.

Open source on GitHub, ad-free, and free to use.
